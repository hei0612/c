歡迎使用卡路里與三大營養素精算 Pro！本系統支援離線紀錄、AI 智能辨識與資料備份，以下為各功能的操作步驟：

1. 📥 今日飲食與三大營養素追蹤
  • 新增食物： 選擇餐次（早餐/午餐/晚餐/小食），輸入食物名稱、熱量（kcal）及三大營養素（蛋白質、碳水、脂肪）後點擊「加入飲食清單」。
  • 快捷標籤與常用食譜： 點擊預設標籤可快速帶入常用食物；你亦可將當前餐次儲存為「⭐ 常用食譜」。
  • 複製昨日餐點： 點擊「🔄 複製昨日同餐次」，系統會自動將昨日同一餐次的食物複製到今天。
2. 🔍 API 資料庫與 Gemini AI 拍照識圖
  • 條碼 / 關鍵字搜尋： 輸入食品名稱或包裝條碼（例如 737628064502），系統會透過 Open Food Facts API 自動帶入每 100g 的營養數據。
  • AI 拍照辨識： 輸入你的 Google Gemini API Key，點擊「📸 分析照片」上傳食物相片，AI 會自動預估食物名稱與卡路里。
3. 🧮 BMR & TDEE 計算器
  • 目標設定： 輸入性別、年齡、身高、體重與每週活動量，選擇「減脂 / 增肌 / 維持」目標及飲食比例。
  • 一鍵同步： 計算出建議每日熱量與三大營養素配額後，點擊「🎯 自動同步熱量與三大營養素目標至今日」，系統會即時更新你的每日目標。
4. 📊 趨勢圖表與資料備份 (JSON / CSV)
  • 7 日趨勢圖： Canvas 圖表會自動繪製近 7 天的熱量攝取曲線與目標橙線對比。
  • 資料歸檔： 每日過後系統會自動歸檔紀錄；你亦可以點擊「💾 歸檔今日」手動儲存。
  • 匯出與匯入： 支援將所有數據匯出為 .json 備份檔，或匯出 .csv 格式供 Excel 開啟；換裝置時只需讀取 JSON 檔即可完整還原資料。
